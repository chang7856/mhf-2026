# Event Design Kit｜活動設計 Claude Skill

拿到活動主視覺之後，用 Claude 做完講者圖、背板、社群素材和活動網站。

## 怎麼用

開一個新的 Claude 對話，貼上這句：

```
請先讀 https://raw.githubusercontent.com/chang7856/mhf-2026/main/skill/event-design-kit/SKILL.md ，照裡面的流程當我的活動設計師。
```

Claude 會告訴你要準備什麼，一步一步帶你做。
