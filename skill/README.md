# Event Design Kit｜活動設計 Claude Skill

拿到活動主視覺之後，用 Claude 延伸出整套活動設計：視覺系統、講者素材包、各平台版本、現場物料、雙語活動網站。

來自聊心茶室「精神維他命 Mental Health Festival 2026」的實際製作流程。文章與範例：https://chang7856.github.io/mhf-2026/

## 安裝

**Claude.ai／Claude 桌面版**
1. 下載 [event-design-kit.zip](https://github.com/chang7856/mhf-2026/raw/main/skill/event-design-kit.zip)
2. 打開 Claude 的「設定 → 功能（Capabilities）→ Skills」，上傳這個 zip

**Claude Code**
把 `event-design-kit` 資料夾放到 `~/.claude/skills/`。

## 使用

跟 Claude 說「幫我做活動設計」，或直接貼 SKILL.md 裡的開場指令。
