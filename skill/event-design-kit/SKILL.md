# 活動設計工具包（Event Design Kit）

這份 skill 來自聊心茶室「精神維他命 Mental Health Festival 2026」的實際製作流程。主視覺由插畫家完成後，其餘的延伸設計用 AI 在兩天內做完。這份 skill 的目標是把同樣的事縮到兩小時。

## 開始前，先跟使用者要齊這些東西

一次問完，不要做到一半才問：

1. 主視覺與插畫的原檔（雲端資料夾或上傳），**原圖照用，不要重畫**
2. 一位參考設計師，以及他的 IG 或作品集連結
3. 活動資料：活動名稱、日期、時間、地點、票價、報名連結
4. 講者資料表：姓名、身份、一句 selling point、場次、照片
5. 品牌名稱的正確寫法
6. 要上的平台（活動通、Luma、IG、Threads、LinkedIn、LINE、Facebook）

缺任何一項，列出來問使用者。**數字和名稱查不到，就問，不要自己補。**

## 設計規則（每一步都要遵守）

- 品牌名稱每次都要寫對
- 不要小字標籤、註記、header、footer 小字。只放時間、主題、講者的 selling point
- 中文斷行不能斷在詞中間；手機上能一行就不要拆兩行
- 中英文分開切換，不要混在同一行
- 每個設計決定附一句理由（例如：活動名稱裡哪個字用強調色、為什麼）
- 手機版優先，做完用手機尺寸檢查；有動畫要在 iPhone 上確認
- 每一步先給原型或靜態畫面，使用者點頭才做下一步

## 流程

### 1. 視覺系統頁

以參考設計師的風格為基礎，融合主視覺。產出一頁視覺系統：

- 色彩（4 到 6 個）、字體（展示字 + 內文字）、版型規則
- 示範：主視覺延伸版、講者卡、票卡各一張
- 每個決定寫一句理由

使用者點頭後才往下。

### 2. 每位講者的素材包

每位講者一包，讓講者自己下載就能發：

| 檔案 | 尺寸 |
|---|---|
| 講者卡 | 4:5，1080 × 1350 |
| 分享海報 | 4:5，1080 × 1350 |
| 限動 | 9:16，1080 × 1920 |
| LinkedIn 連結圖 | 1200 × 627 |
| 雜誌跨頁（輪播用） | 3:2 |
| 50 字以內的介紹 | 文字檔 |

主持人另外加：主持人海報、簡報講者頁。
把檔案放進雲端資料夾，檔名標清楚平台（IG／LinkedIn／LINE）。

### 3. 各平台版本

| 平台 | 尺寸 |
|---|---|
| 活動通主圖 | 2:1，1200 × 600 |
| Luma 封面 | 1:1，至少 800 × 800（四角會被裁圓） |
| IG 貼文／限動 | 1080 × 1350／1080 × 1920 |
| Threads | 1:1，1080 × 1080 |
| LINE／連結分享圖 | 1200 × 630 |
| LinkedIn 個人 banner | 1584 × 396（左下角會被大頭貼蓋住） |
| LinkedIn 大頭貼 | 400 × 400 |
| Facebook 活動封面 | 1920 × 1005 |

小巧思：LinkedIn banner 的角色可以「圍著」大頭貼，大頭貼加活動色外框；品牌 logo 不換，但可以做活動限定版（像 Duolingo 的節日換裝）。

### 4. 現場物料

舞台背板 16:9、票卡（依票種用顏色區分）、工作人員／講者名牌、活動手冊（每個空間一頁）、拍照牆、房間告示牌、貼紙。

### 5. 活動網站

一頁式，中英雙語（依瀏覽器語言自動切換，右上角可手動切換），手機優先。區塊順序照讀者心裡的問題：

1. 這是什麼活動（一句話主軸）
2. 裡面有什麼（場次、空間）
3. 誰會來（講者名牌牆 → 講者介紹）
4. 在哪裡（地址、地圖）
5. 多少錢、幾點開始（票價、流程，購票按鈕連到報名頁）
6. 追蹤我們（品牌介紹、IG、官網）

手機底部固定購票列。上線前設定：

- 專用分享圖 1200 × 630、網站圖示
- 標題：英文活動名＋中文名
- 描述：先寫時間，再寫亮點
- 實際分享到 LINE、IG、WhatsApp 測試；預覽被快取時，在網址後加 `?v=2`

## 直接可用的開場指令

使用者也可以直接貼這段：

```
你是我的活動設計師。
請參考［設計師名字］的風格（［IG 連結］），融合我給的主視覺和插畫（原圖照用，不要重畫），做一套完整的活動設計系統。

活動資料：［活動通連結］、［講者資料表］、［主視覺與插畫的雲端資料夾］

要做的東西：
1. 視覺系統頁：色彩、字體、版型規則，每個設計決定寫一句理由
2. 每位講者：講者卡 4:5、分享海報 4:5、限動 9:16、LinkedIn 連結圖 1200×627，附 50 字介紹
3. 現場：舞台背板 16:9、票卡、名牌、活動手冊、拍照牆、告示牌、貼紙
4. 社群：活動通 2:1、Luma 1:1、Threads 1:1、LINE 分享圖 1200×630、LinkedIn banner 1584×396
5. 活動網站：中英雙語、手機優先、購票按鈕、分享縮圖與描述

規則：
- 品牌名稱是「［品牌名］」，每次都要對
- 不要小字標籤，只放時間、主題、講者的 selling point
- 中文斷行不能斷在詞中間
- 中英文分開切換，不要混在一起
- 數字和名稱都要有來源，查不到就問我，不要自己補
- 每一步先給我看原型，我點頭再做下一步
```
